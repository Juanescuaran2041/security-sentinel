# A05:2021 — Security Misconfiguration

## Descripción

Mala configuración de seguridad es la categoría más frecuente. Ocurre cuando la aplicación, frameworks, servidor de aplicación, servidor web, o base de datos están configurados de forma insegura. Incluye configuraciones por defecto inseguras, configuraciones incompletas, headers HTTP faltantes, y mensajes de error verbosos.

## CWEs relacionados

- CWE-16 (Configuration)
- CWE-611 (XXE)
- CWE-1004 (Sensitive Cookie Without 'HttpOnly' Flag)
- CWE-942 (Permissive Cross-domain Policy)

## Indicadores en code review

- Debug mode habilitado en producción (`DEBUG=True` en Django, Flask)
- CORS permisivo: `Access-Control-Allow-Origin: *`
- Headers de seguridad faltantes (CSP, X-Frame-Options, HSTS)
- Manejo de errores que expone stack traces o información interna
- Servicios innecesarios habilitados (directory listing, admin panels)
- Dependencias con vulnerabilidades conocidas sin patchear

## Mitigaciones

- Proceso de hardening reproducible (Infrastructure as Code)
- Plataforma mínima: remover features, frameworks, y componentes no usados
- Revisar y actualizar configuraciones como parte del proceso de patching
- Usar headers de seguridad apropiados
- Proceso automatizado para verificar efectividad de configuraciones
- Ambientes de desarrollo, QA, y producción configurados de forma idéntica (excepto credenciales)

## Severidad típica

MEDIUM — pero puede escalar a HIGH/CRITICAL si expone info que facilita otros ataques.
