# A02:2021 — Cryptographic Failures

## Descripción

Fallas criptográficas (antes conocido como "Sensitive Data Exposure") se refiere a fallas relacionadas con criptografía que frecuentemente llevan a exposición de datos sensibles. Incluye uso de algoritmos débiles, gestión inadecuada de claves, y transmisión de datos sin cifrar.

## CWEs relacionados

- CWE-327 (Use of a Broken or Risky Cryptographic Algorithm)
- CWE-328 (Use of Weak Hash)
- CWE-330 (Use of Insufficiently Random Values)
- CWE-311 (Missing Encryption of Sensitive Data)

## Indicadores en code review

- Uso de MD5, SHA-1, DES, RC4, o Blowfish
- Almacenamiento de contraseñas con hash simple (sin salt, sin key stretching)
- Claves de cifrado hardcodeadas o predecibles
- Transmisión de datos sensibles sin TLS
- Uso de ECB mode en cifrado por bloques
- Random seeds predecibles para operaciones de seguridad

## Mitigaciones

- Clasificar datos según sensibilidad y aplicar controles apropiados
- No almacenar datos sensibles innecesariamente
- Cifrar datos en reposo y en tránsito con algoritmos actuales (AES-256, RSA-2048+)
- Usar funciones de hash con salt para contraseñas (bcrypt, argon2, scrypt)
- Usar generadores de números aleatorios criptográficamente seguros (`secrets` en Python)
- Deshabilitar caching para respuestas que contengan datos sensibles

## Severidad típica

HIGH a CRITICAL — la exposición de datos sensibles tiene impacto directo en confidencialidad.
