# A07:2021 — Identification and Authentication Failures

## Descripción

Fallas de identificación y autenticación ocurren cuando las funciones de la aplicación relacionadas con la identidad del usuario, autenticación o gestión de sesiones no se implementan correctamente, permitiendo a atacantes comprometer contraseñas, claves, tokens de sesión, o explotar otras fallas para asumir la identidad de otros usuarios.

## CWEs relacionados

- CWE-798 (Use of Hard-coded Credentials)
- CWE-287 (Improper Authentication)
- CWE-384 (Session Fixation)
- CWE-256 (Plaintext Storage of a Password)
- CWE-307 (Improper Restriction of Excessive Authentication Attempts)

## Indicadores en code review

- Credenciales hardcodeadas (passwords, API keys, tokens)
- Ausencia de rate limiting en login/registration
- Almacenamiento de contraseñas en texto plano o con hash débil
- Session tokens predecibles o no rotados tras login
- Exposición de session IDs en URLs
- Falta de MFA para operaciones sensibles

## Mitigaciones

- Implementar MFA donde sea posible
- No desplegar con credenciales por defecto
- Implementar rate limiting y lockout temporal en autenticación
- Usar gestores de sesiones seguros del framework (tokens aleatorios, httponly, secure)
- Almacenar contraseñas con funciones de hash adaptativas (bcrypt, argon2)
- Usar variables de entorno o gestores de secretos para credenciales

## Severidad típica

HIGH a CRITICAL — el compromiso de autenticación frecuentemente otorga acceso completo.
