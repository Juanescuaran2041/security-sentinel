# A06:2021 — Vulnerable and Outdated Components

## Descripción

Uso de componentes (librerías, frameworks, módulos) con vulnerabilidades conocidas. Incluye dependencias directas y transitivas desactualizadas donde existen CVEs publicados. Es particularmente relevante en ecosistemas con gestores de paquetes (npm, PyPI, crates.io).

## CWEs relacionados

- CWE-1104 (Use of Unmaintained Third-Party Components)
- CWE-937 (Using Components with Known Vulnerabilities)

## Indicadores en code review

- Dependencias sin version pinning (ej: `requests>=2.0` en vez de `requests==2.31.0`)
- Lockfiles desactualizados o no committeados
- Dependencias con CVEs conocidos sin actualizar
- Uso de paquetes deprecados o abandonados
- Falta de proceso de actualización regular

## Mitigaciones

- Remover dependencias no usadas
- Inventariar versiones de componentes client-side y server-side continuamente
- Monitorear fuentes como CVE, NVD, OSV.dev para vulnerabilidades en componentes
- Solo obtener componentes de fuentes oficiales vía enlaces seguros
- Monitorear librerías y componentes que no reciben mantenimiento
- Usar herramientas como `pip-audit`, `npm audit`, `cargo audit`

## Severidad típica

Variable — depende del CVE específico. Puede ser desde INFO hasta CRITICAL.
