# A09:2021 — Security Logging and Monitoring Failures

## Descripción

Fallas de logging y monitoreo de seguridad impiden la detección, escalamiento y respuesta a ataques activos. Sin logging suficiente, los atacantes pueden pivotar, extraer datos, y mantener persistencia sin ser detectados.

## CWEs relacionados

- CWE-778 (Insufficient Logging)
- CWE-117 (Improper Output Neutralization for Logs)
- CWE-223 (Omission of Security-relevant Information)

## Indicadores en code review

- Eventos auditables (login, login fallido, transacciones de alto valor) no se registran
- Logs que no incluyen contexto suficiente (quién, qué, cuándo, desde dónde)
- Warnings y errores que no generan mensajes de log
- Logs almacenados solo localmente sin backup
- Ausencia de alertas para actividad sospechosa
- Log injection posible (input del usuario escrito directamente en logs)

## Mitigaciones

- Asegurar que todos los fallos de login, control de acceso, y validación de input se loguean con contexto suficiente
- Asegurar que los logs se generan en formato consumible por soluciones de log management
- Asegurar que los datos de log están codificados correctamente para prevenir injection en logs
- Establecer monitoreo y alertas para actividades sospechosas
- Establecer un plan de respuesta a incidentes
- Usar formatos de log estructurado (JSON) con correlation IDs

## Severidad típica

MEDIUM — no es una vulnerabilidad directa, pero facilita la explotación prolongada de otras.
