# A08:2021 — Software and Data Integrity Failures

## Descripción

Fallas de integridad de software y datos se relacionan con código e infraestructura que no protege contra violaciones de integridad. Incluye uso de plugins, librerías o módulos de fuentes no confiables, pipelines CI/CD inseguros, y deserialización insegura de datos.

## CWEs relacionados

- CWE-502 (Deserialization of Untrusted Data)
- CWE-829 (Inclusion of Functionality from Untrusted Control Sphere)
- CWE-494 (Download of Code Without Integrity Check)

## Indicadores en code review

- Uso de `pickle.loads()`, `yaml.load()` sin SafeLoader, `eval()` con datos externos
- Dependencias cargadas desde CDNs sin integrity hash (SRI)
- Pipelines CI/CD sin verificación de integridad de artefactos
- Auto-update sin verificación de firma
- Deserialización de cookies, tokens, o datos de red sin validación

## Mitigaciones

- Usar firmas digitales para verificar integridad de software/datos
- Asegurar que librerías y dependencias vienen de repositorios confiables
- Usar herramientas de análisis de composición de software (SCA) como OWASP Dependency-Check
- Asegurar que el pipeline CI/CD tiene separación, configuración, y control de acceso apropiados
- No enviar datos serializados sin firmar o sin cifrar a clientes no confiables
- Usar `yaml.safe_load()`, JSON, o Protocol Buffers en lugar de pickle

## Severidad típica

HIGH a CRITICAL — la deserialización insegura frecuentemente lleva a RCE.
