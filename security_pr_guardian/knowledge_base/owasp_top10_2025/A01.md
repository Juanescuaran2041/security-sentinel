# A01:2021 — Broken Access Control

## Descripción

Control de acceso roto permite a usuarios actuar fuera de sus permisos previstos. Las fallas típicamente llevan a divulgación, modificación o destrucción no autorizada de datos, o ejecución de funciones de negocio fuera de los límites del usuario.

## CWEs relacionados

- CWE-552 (Files or Directories Accessible to External Parties)
- CWE-22 (Path Traversal)
- CWE-425 (Forced Browsing)
- CWE-862 (Missing Authorization)

## Indicadores en code review

- Falta de verificación de permisos en endpoints
- IDOR (Insecure Direct Object Reference): acceso a recursos por ID sin verificar ownership
- Path traversal: `../` en rutas de archivo sin validación
- Escalamiento vertical: acceso a funciones de admin sin verificación de rol
- CORS misconfigured: `Access-Control-Allow-Origin: *` con credenciales

## Mitigaciones

- Denegar por defecto, excepto recursos públicos
- Implementar mecanismos de control de acceso una vez y reutilizarlos en toda la aplicación
- Verificar ownership en cada acceso a recurso (no solo autenticación, sino autorización)
- Deshabilitar listado de directorios del servidor web
- Log de fallos de control de acceso y alertar a administradores
- Rate limit acceso a APIs para minimizar daño de herramientas automatizadas

## Severidad típica

CRITICAL a HIGH — el acceso no autorizado frecuentemente tiene impacto directo en confidencialidad e integridad.
