# CWE-552: Files or Directories Accessible to External Parties

## Descripción

Referencias a rutas de archivos sensibles del sistema en el código que pueden exponer información confidencial. Incluye acceso directo a archivos de configuración del sistema, claves SSH, archivos de contraseñas, y otros recursos que no deberían ser accesibles desde una aplicación.

## Impacto

- Lectura de credenciales del sistema (`/etc/shadow`)
- Acceso a claves privadas SSH y certificados
- Exposición de configuraciones de red y servicios
- Information disclosure para facilitar ataques posteriores
- Path traversal cuando se combina con input del usuario

## Rutas sensibles comunes

| Ruta | Contenido sensible |
|------|-------------------|
| `/etc/passwd` | Usuarios del sistema |
| `/etc/shadow` | Hashes de contraseñas |
| `~/.ssh/id_rsa` | Clave privada SSH |
| `~/.ssh/authorized_keys` | Keys de acceso SSH |
| `/etc/hosts` | Resolución de nombres interna |
| `~/.aws/credentials` | Credenciales AWS |
| `~/.kube/config` | Config de Kubernetes |
| `/proc/self/environ` | Variables de entorno del proceso |

## Patrones vulnerables típicos

```python
# Lectura directa de archivos sensibles
with open("/etc/passwd") as f:
    users = f.read()

# Referencia a claves SSH
key_path = os.path.expanduser("~/.ssh/id_rsa")
private_key = open(key_path).read()

# Path traversal con input del usuario
filepath = f"/var/data/{user_input}"  # ../../etc/shadow
content = open(filepath).read()

# Exposición de /proc
environ = open("/proc/self/environ").read()
```

## Remediación

- **Nunca hardcodear rutas a archivos sensibles del sistema**
- Validar y sanitizar paths con `os.path.realpath()` + verificación de prefijo
- Usar `pathlib.Path.resolve()` y verificar que el resultado está dentro del directorio permitido
- Implementar chroot o containerización para limitar acceso al filesystem
- Usar gestores de secretos en lugar de leer archivos de credenciales directamente

## Código corregido

```python
# Validación de path traversal
from pathlib import Path

BASE_DIR = Path("/var/data")

def safe_read(user_filename: str) -> str:
    requested = (BASE_DIR / user_filename).resolve()
    if not str(requested).startswith(str(BASE_DIR.resolve())):
        raise ValueError("Path traversal detected")
    return requested.read_text()

# Para credenciales - usar variables de entorno
import os
ssh_key = os.environ.get("SSH_PRIVATE_KEY")  # inyectada por el runtime

# O usar gestores de secretos
import boto3
client = boto3.client("secretsmanager")
response = client.get_secret_value(SecretId="prod/ssh-key")
```
