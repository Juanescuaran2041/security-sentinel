# CWE-502: Deserialization of Untrusted Data

## Descripción

Deserialización insegura ocurre cuando una aplicación deserializa datos de una fuente no confiable sin validación. En lenguajes como Python, Java y PHP, la deserialización puede ejecutar código arbitrario durante el proceso de reconstrucción de objetos.

## Impacto

- Remote Code Execution (RCE) — el impacto más común y severo
- Denial of Service (objetos con alto consumo de memoria/CPU)
- Bypass de autenticación (manipulación de tokens serializados)
- Escalamiento de privilegios

## Vectores de ataque comunes

- `pickle.loads()` con datos de red, archivos, o cookies
- `yaml.load()` sin `Loader=SafeLoader` (permite `!!python/object`)
- `eval()` sobre strings de fuentes externas
- `marshal.loads()` con datos no confiables
- Java `ObjectInputStream.readObject()` con gadget chains

## Patrones vulnerables típicos

```python
# Python - pickle con datos de red
import pickle
data = pickle.loads(request.data)  # RCE directo

# Python - yaml sin SafeLoader
import yaml
config = yaml.load(user_uploaded_file)  # permite !!python/object

# Python - eval con input externo
result = eval(request.form['expression'])

# Python - marshal
import marshal
code = marshal.loads(uploaded_bytes)
```

## Remediación

- **Nunca deserializar datos no confiables con pickle/marshal**
- Usar `yaml.safe_load()` o `yaml.load(data, Loader=yaml.SafeLoader)` siempre
- Reemplazar `eval()` con `ast.literal_eval()` para expresiones simples
- Usar formatos seguros: JSON, MessagePack, Protocol Buffers
- Si pickle es inevitable, usar `hmac` para firmar datos antes de deserializar
- Implementar allowlists de clases permitidas para deserialización

## Código corregido

```python
# YAML seguro
import yaml
config = yaml.safe_load(user_file)  # solo tipos básicos Python

# Reemplazo de eval
import ast
result = ast.literal_eval(expression)  # solo literales: strings, numbers, tuples, lists, dicts

# Usar JSON en lugar de pickle
import json
data = json.loads(request.data)  # sin ejecución de código

# Si pickle es necesario, firmar con HMAC
import hmac, hashlib, pickle
expected_mac = hmac.new(secret_key, serialized, hashlib.sha256).digest()
if hmac.compare_digest(received_mac, expected_mac):
    data = pickle.loads(serialized)
```
