# CWE-327: Use of a Broken or Risky Cryptographic Algorithm

## Descripción

Uso de algoritmos criptográficos rotos, débiles o no apropiados para el propósito. Incluye funciones hash obsoletas (MD5, SHA-1) para verificación de integridad o almacenamiento de contraseñas, y cifrados simétricos débiles (DES, RC4).

## Impacto

- Colisiones de hash que permiten falsificación de firmas
- Cracking de contraseñas almacenadas con hashes débiles
- Descifrado de datos protegidos con algoritmos rotos
- Falsificación de certificados digitales
- Violación de estándares de compliance (PCI-DSS requiere AES-256)

## Algoritmos considerados rotos/débiles

| Algoritmo | Estado | Alternativa segura |
|-----------|--------|-------------------|
| MD5 | Roto (colisiones triviales) | SHA-256, SHA-3, BLAKE2 |
| SHA-1 | Roto (colisiones demostradas 2017) | SHA-256, SHA-3 |
| DES | Roto (56-bit key) | AES-256 |
| 3DES | Deprecated (2023) | AES-256 |
| RC4 | Roto | ChaCha20-Poly1305 |
| Blowfish | Deprecated para nuevos usos | AES-256 |

## Patrones vulnerables típicos

```python
# Hash débil para contraseñas
import hashlib
password_hash = hashlib.md5(password.encode()).hexdigest()
token = hashlib.sha1(secret.encode()).hexdigest()

# Cifrado débil
from Crypto.Cipher import DES
cipher = DES.new(key, DES.MODE_ECB)

# HMAC con hash débil
import hmac
hmac.new(key, msg, hashlib.md5)
```

## Remediación

- **Para contraseñas**: usar `bcrypt`, `argon2`, o `scrypt` — nunca hash simple
- **Para integridad**: usar SHA-256, SHA-3, o BLAKE2b
- **Para cifrado simétrico**: usar AES-256-GCM o ChaCha20-Poly1305
- **Para HMAC**: usar HMAC-SHA-256 mínimo
- Nunca usar ECB mode para cifrado por bloques

## Código corregido

```python
# Contraseñas - bcrypt
import bcrypt
hashed = bcrypt.hashpw(password.encode(), bcrypt.gensalt())

# Integridad - SHA-256
import hashlib
digest = hashlib.sha256(data).hexdigest()

# Cifrado - AES-GCM
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
key = AESGCM.generate_key(bit_length=256)
aesgcm = AESGCM(key)
ct = aesgcm.encrypt(nonce, plaintext, associated_data)

# HMAC seguro
import hmac, hashlib
mac = hmac.new(key, msg, hashlib.sha256).digest()
```
