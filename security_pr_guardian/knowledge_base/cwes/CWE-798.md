# CWE-798: Use of Hard-coded Credentials

## Descripción

Credenciales hardcodeadas son contraseñas, API keys, tokens o secretos embebidos directamente en el código fuente. Una vez publicado el código (repo público, binario distribuido, imagen Docker), cualquier persona con acceso puede extraer las credenciales.

## Impacto

- Acceso no autorizado a sistemas y APIs
- Compromiso de cuentas de servicio
- Imposibilidad de rotar credenciales sin redespliegue
- Movimiento lateral usando credenciales expuestas
- Violación de compliance (PCI-DSS, SOC 2, HIPAA)

## Vectores de ataque comunes

- Asignación directa a variables con nombres sugestivos (`password = "..."`)
- Strings con formato de API key en constantes
- Tokens de autenticación en configuraciones committeadas
- Credenciales de base de datos en el código
- Archivos `.env` committeados por error

## Patrones vulnerables típicos

```python
# Contraseña hardcodeada
DB_PASSWORD = "super_secret_123"
password = "admin123"

# API key directa
API_KEY = "sk-proj-abc123def456..."
STRIPE_SECRET = "sk_live_..."

# Token de autenticación
AUTH_TOKEN = "ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
aws_secret_access_key = "wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY"

# Connection string con credenciales
DATABASE_URL = "postgresql://admin:password123@prod-db.example.com:5432/myapp"
```

## Remediación

- **Usar variables de entorno** para todas las credenciales
- Usar gestores de secretos: AWS Secrets Manager, HashiCorp Vault, Azure Key Vault
- Usar archivos `.env` locales (nunca committeados, siempre en `.gitignore`)
- Rotar credenciales inmediatamente si se detecta exposición
- Implementar pre-commit hooks que detecten secretos (git-secrets, truffleHog)
- Usar IAM roles en lugar de access keys cuando sea posible (AWS)

## Código corregido

```python
# Variables de entorno
import os
DB_PASSWORD = os.environ["DB_PASSWORD"]
API_KEY = os.environ.get("API_KEY")

# Pydantic Settings (recomendado en este proyecto)
from pydantic_settings import BaseSettings
class Config(BaseSettings):
    db_password: str
    api_key: str
    class Config:
        env_file = ".env"

# AWS Secrets Manager
import boto3
client = boto3.client("secretsmanager")
secret = client.get_secret_value(SecretId="my-app/db-password")
```
